## 00:00:00 — A narrow, inspectable read path.

Buffer separates the interface, scenario engine, and live provider. Next J S renders normalized snapshots. Server routes contain Drift and Solana access. Reading positions uses no private key and requests no transaction signature.

## 00:00:14 — Verify before calculating.

The provider validates the public authority and selected subaccount, then verifies mainnet, account ownership, and decoded identity. It gathers required markets and oracles before normalization. Incomplete coverage stays visible instead of becoming a partial baseline.

## 00:00:30 — Signed quantity × price × move.

The formula is signed base quantity, times frozen oracle price, times shock fraction. Decimal strings preserve precision. Only contributions with the same verified quote currency are added. Position sizes stay fixed throughout the scenario.

## 00:00:59 — Coverage is part of the result.

Eligible SOL, Bitcoin, and Ether linear perpetuals enter the model. Excluded contracts keep their reasons. Collateral, debt, and orders remain separate inventory. Baseline metrics do not become hypothetical equity, future health, or liquidation thresholds.

## 00:01:16 — Freshness is explicit.

Live snapshots expire after one hundred twenty seconds. A failed refresh pauses calculation. Account, market, and oracle observations can come from different slots. Buffer preserves that provenance instead of claiming an atomic same slot read.

## 00:01:30 — Export enough to reproduce it.

The JSON export includes source, snapshot, shock, contributions, exclusions, quote totals, and assumptions. Tests cover the scenario, provider boundaries, and browser flows. Mocked tests validate behavior; they do not establish successful mainnet integration.

## 00:01:48 — Small surface. Clear guarantees.

Live verification requires a working server side Solana endpoint and a suitable public Drift authority. Optional account services require their configured backend. This walkthrough uses deterministic samples, keeping implemented behavior and integration limits explicit.
