# Pacifica market artwork

These files identify underlying assets available in Buffer’s Pacifica market registry. They are unchanged bytes downloaded on 2026-09-12. They are not an assertion that Pacifica supplied the third-party token art or that the projects endorse Buffer.

- Pacifica’s own icon comes from its official website.
- Flash Trade assets come from its official production starter, pinned to Git commit `3e6202eea545aaa88dd0db8eec899175c837af03`. Its asset NOTICE says the files come from Flash Trade’s production web client/CDN and that token logos remain their respective projects’ property. Original NOTICE: https://github.com/flash-trade/examples-v2/blob/3e6202eea545aaa88dd0db8eec899175c837af03/examples/tap-trade/public/token-icons/NOTICE . The starter’s MIT license does not transfer token trademarks.
- Other underlying-token and RWA icons come unchanged from Hyperliquid’s official web application. Third-party trademarks remain with their owners.
- kBONK, kPEPE and kSHIB use the corresponding underlying token logo while retaining the scaled market label in Buffer. CL uses Flash’s crude-oil artwork; PLATINUM uses its XPT artwork. EURUSD uses Hyperliquid’s EUR contract artwork.
- Existing SOL, BTC, ETH and HYPE assets remain in the parent directory; this mapping does not replace them.
- BP, PIPPIN, SAMSUNG, SKHYNIX, SPCX and URNM have no verified asset here. Buffer renders their explicit symbols instead of substituting an unrelated logo.
- Each SVG was checked for scripts, event handlers, foreign objects and external resource URLs. Raster signatures and rendering dimensions were checked. A few original file extensions were misleading; local extensions follow the actual file format without changing the bytes.
